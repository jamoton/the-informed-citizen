# The Informed Citizen — free static website

## Publish with GitHub + Netlify
1. In your GitHub repository, upload **the contents of this folder** (not the enclosing folder). `index.html` must be at repository root.
2. In Netlify, connect this repository, deploy branch `main`, leave build command blank, and set publish directory to `.`.
3. Site pages: `/`, `/investigations/`, `/research/`, `/immigration-crime/`, `/about/`, `/methodology/`.
4. Check links and dashboard tabs on the deployed site.

## Approval workflow
For every update: create a GitHub branch, edit files, open a pull request, review facts and links, then **Merge** to approve. Netlify publishes merged changes automatically. This is not yet an automated research-to-pull-request pipeline. The existing ChatGPT monthly research reminder does not update GitHub.

## Before public promotion
Homepage investigation titles are editorial placeholders, not published articles. Add verified source links and approved copy before promoting them. Verify all dashboard data and Featured Stories links as well.
