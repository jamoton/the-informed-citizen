# Texas DPS records request — draft, NOT SENT
Recipient: publicrecords@dps.texas.gov
Subject: Texas Public Information Act request — de-identified criminal offense records and DHS status linkage methodology

To the Texas Department of Public Safety Public Information Office:

Under the Texas Public Information Act, I request existing electronic records or datasets sufficient to examine the coverage and definitions of the Texas Criminal Illegal Noncitizen Data report for arrest events dated August 15 through November 15, 2026. If records for the full interval are not yet available, please provide the latest available portion and indicate the cutoff date.

Specifically, please provide, to the extent maintained and lawfully releasable:

1. A de-identified incident/arrest-level extract for Texas arrests involving homicide, sexual assault, fatal intoxication-related vehicular offenses, and felony drug manufacturing/delivery/trafficking, with incident/arrest date, county, offense code/description, anonymized stable incident and person identifiers (if available), case disposition and disposition date, and DHS lawful-presence classification as recorded for the event.
2. A separate indication of records identified through Secure Communities fingerprint matching versus those identified while incarcerated in TDCJ, plus dates of status determination when available.
3. Data dictionaries, code lists, deduplication rules, query definitions, and documentation describing the relationship between the published arrest, charge, and conviction counts.
4. Existing aggregate counts for the same offense categories and date interval, separated by status classification and identification pathway, if the underlying records cannot be released.
5. Any existing documentation on missing or unmatched DHS responses, record update schedules, and known limitations of status classification at the time of arrest.
6. Existing research-access procedures for criminal-history data files under Texas Government Code 411.083(b), including eligibility, application requirements and fees.

I do not seek names, birth dates, addresses, immigration identifiers, victims' identities, or other directly identifying information. Please provide segregable non-exempt records if any portion is exempt. If a new custom extract would require programming, please advise what existing reports or files could be provided instead. Please provide electronic files in CSV or other machine-readable form where available.

Before incurring costs over $40, please send a written itemized estimate. If you determine that this request must be narrowed or redirected to another office, please advise.

Sincerely,
The Informed Citizen
[Sender name and contact information to be supplied before sending]

## Internal note
This is an access request, not a claim that Texas DPS possesses or must release all requested fields. Do not send without the user's review. Published Texas DPS aggregate data cannot independently establish the tracker’s incident-level recall.
