# Measuring coverage toward a 75% audited-recall target

**Goal:** recover at least 75% of independently ascertained, *publicly verifiable* qualifying incidents in tested jurisdiction/offense/date strata. This is a target, not a current performance claim.

## Denominator
An independent reference list must be generated without relying on this project's discovered cases. Prefer comprehensive state court/crash/incident records cross-linked to authoritative immigration status evidence. Where no independent status linkage is possible, label recall **not measurable**. Do not use all arrests as a denominator for confirmed unlawful-presence cases.

## Numerator
Distinct qualifying incidents found by the automated discovery workflow **before** seeing the independent reference list. Require incident date, location, offense, source evidence, and immigration-status-at-incident documentation. Freeze discovered list before audit matching.

## Measurement
Recall = qualifying reference incidents found / all qualifying reference incidents. Stratify by state, urban/rural area, offense and source availability; publish denominator and confidence limits if representative sampling is feasible. If source disclosure makes cases unobservable, say so rather than extrapolating.

## Source coverage
The 51-jurisdiction coverage_targets.csv grid is a **to-do inventory**, not evidence of 51 active feeds. Record actual source URL, permissions, date range, queries, retrieval errors, records examined, and deduplication decisions in coverage_audit.csv.

## Privacy and integrity
Do not bypass site controls or collect sealed records. Minimize personal data. Separate alleged and convicted cases. Never infer status from nationality. Include corrections, acquittals and retractions. Publish only after two-person review. A 75% recall result cannot be represented as 75% of all national crimes unless the denominator truly covers all national crimes.
